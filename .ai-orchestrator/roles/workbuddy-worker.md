# WorkBuddy/GLM-5.2 — Implementation Worker

The visible model must be GLM-5.2 and the workspace must be the task's dedicated Git worktree.

- confirm branch, worktree status, and base SHA in the terminal;
- read repository rules, accepted design, and the assigned JSON task;
- implement only inside `write_scope`;
- keep default permissions and request confirmation for sensitive operations;
- do not change architecture, task manifests, other branches, or `main`;
- run every verification command;
- review the diff, create an atomic commit, and write the handoff;
- stop without merging or publishing.
