2. **Any per-sector failure marks the whole Guba source `unavailable`** (`mom_index/collectors/guba.py:234-241`), discarding sectors that did parse. This is stricter than R2's "zero-post live result is flagged as a warning," but it is the only behavior consistent with `merge_success`'s all-four-sectors invariant and with the decisions.md clarification that zero valid posts is not a live success. Conservative and honest; acceptable.
3. **The local Playwright XHS path is now a non-functional boundary stub** (`mom_index/collectors/xhs_playwright.py:40-43` returns `unavailable` even when configured). The design listed it as "local-only," and dropping the old Windows-only capability is aligned with D3 and the non-goals, and is documented in the T-001 handoff — but it is a small capability removal made without an ADR.
4. **Top posts without a `source_url` are silently excluded** (`scoring.py:132`) to work around the schema's `oneOf` for `source_url` with format checking off. Harmless for Guba (every parsed post has a URL), documented in the T-002 handoff; revise to `anyOf` in a future schema revision.
