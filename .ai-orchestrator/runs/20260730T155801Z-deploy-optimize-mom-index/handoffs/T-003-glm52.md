## How the deliverables map to acceptance criteria

- **index.html + relative assets + single payload**: `build_site.py` produces
  `_site/{index.html, assets/*, data/dashboard_data.json}` with only relative
  references; `check_site.py` confirms no absolute/CDN runtime URLs and every
  referenced asset exists.
- **Useful shell when Chart.js fails**: `app.js` checks
  `typeof window.Chart === "function"`; if false, each chart slot renders an
  honest `chart-fallback` history table (or "暂无历史数据"). Cards, status,
  methodology, and footer render independently of Chart.js. Empty payloads
  show an explicit insufficient-history state, never invented charts.
- **Unavailable/simulated visibly distinct; stale recomputed client-side**:
  source badges use distinct colors/labels (实时/模拟/不可用). Stale banner
  shown when `freshness.is_stale` OR when the browser recomputes
  `now - generated_at > stale_after_hours`.
- **No Douyin / no XHS-as-live**: footer is rendered dynamically from
  `payload.sources` (no hardcoded source list); `check_site.py` rejects
  `抖音`/`Douyin` anywhere and rejects an `xiaohongshu` source with
  `mode: "live"` in the public payload.
- **No spinner after success/error; no 375px overflow; safe external links**:
  `renderTopPosts` replaces `innerHTML` entirely (fixes the
  `innerHTML +=` spinner-forever bug); charts grid uses
  `minmax(280px, 1fr)` and drops to a single column `<=600px`; post
  `source_url` links use `target="_blank" rel="noopener noreferrer nofollow"`.
- **Build/smoke pass; scope respected**: confirmed above.

## Known risks

1. **Chart.js vendored from jsDelivr at build time only.** The runtime is
   fully vendored (`frontend/assets/chart.umd.min.js`, 205 KB) — no runtime
   CDN dependency. The file was fetched once during implementation to vendor
   it; the published artifact never depends on jsDelivr. If a future Chart.js
   update is desired, re-vendor and re-run `check_site.py`.
2. **Client-side staleness uses `Date.now()` vs `generated_at` (UTC).** This
   is correct for the `Asia/Shanghai` display timezone (the payload carries
   UTC `generated_at`). If a viewer's clock is skewed, the stale banner may
   appear early/late; the payload's own `freshness.is_stale` is also rendered
   so server-side staleness is always honored.
3. **`check_site.py` secret scan skips `chart.umd.min.js` for keyword
   patterns** (third-party minified JS would false-positive on words like
   "token" in Chart.js internals) but still scans it for forbidden source
   terms (`抖音`/`Douyin`). This is a deliberate, documented trade-off; the
   vendored file is MIT-licensed and its integrity is the responsibility of
   the vendoring step.
4. **`buy_sell_ratio` null rendering**: per design, `null` (sell_count=0)
   renders as `∞` with a "🩸卖方缺失" tag. This matches the design contract
   ("null when sell_count=0, UI renders ∞").
5. **No browser-based visual regression was run** (no headless browser in
   scope). Rendering was verified via syntax check, schema validation,
   positive/negative smoke tests, and structural review. T-004 (docs/integration)
   or a later step may add a headless browser gate if desired — that would be
   a new dependency and out of T-003 scope.
